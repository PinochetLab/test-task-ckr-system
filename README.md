# Test Task — CKR System

В этом репозитории представлено выполненное тестовое задание на позицию Unity-разработчика: мобильное приложение из трёх вкладок, которые переключаются через нижнюю навигационную панель. Все запросы к серверу проходят через общую очередь и выполняются строго друг за другом.

## Вкладки

| Вкладка | Что делает |
|---|---|
| **Кликер** | Кнопка начисляет валюту, автосбор срабатывает каждые 3 сек, энергия тратится на клики и восстанавливается со временем. VFX: частицы, вылет валюты, анимация кнопки, звук. |
| **Погода** | Пока вкладка открыта, каждые 5 сек запрашивает прогноз с [api.weather.gov](https://api.weather.gov/gridpoints/TOP/32,81/forecast) и выводит `(иконка) Сегодня - 61F`. |
| **Породы собак** | Список из 10 пород с [dogapi.dog](https://dogapi.dog/docs/api-v2). По клику на породу загружает её описание и показывает в поп-апе. |

При переходе на другую вкладку или при выборе другой породы активный запрос отменяется, а ожидающий удаляется из очереди.

## Стек

- **Unity** 6000.5.6f1, URP 2D
- **Zenject**: DI, фабрики и пулы
- **UnityWebRequest**: работа с сетью
- **UniRx + UniTask**, **DOTween**
- Архитектура **MVP**, без синглтонов

Все настраиваемые значения (стоимости, награды, балансы) вынесены в ScriptableObject, а UI адаптируется под разные разрешения экрана.

## Архитектура

Структура папок, описание классов и UML-диаграммы лежат в [Docs/Architecture.md](Docs/Architecture.md).

## Запуск

1. Клонировать репозиторий.
2. Открыть папку в Unity Hub (версия 6000.5.6f1). UniTask, Extenject (Zenject) и Newtonsoft.Json подтянутся сами через `Packages/manifest.json`. UniRx и DOTween уже лежат в репозитории (`Assets/Plugins/UniRx`, `Assets/Plugins/Demigiant`).
3. Открыть сцену `Assets/Scenes/Main.unity`, выставить в Game view портретное разрешение (например, 1080×1920) и нажать Play.

Тесты: **Window → General → Test Runner → EditMode → Run All**.
